# V0 请求链

1. **本阶段目标**：观察 HTTP 请求进入 Java 后返回 JSON。
2. **上一阶段有什么**：空仓库与两份待整理的示例压缩包。
3. **本阶段新增什么**：Spring Boot、Vue 表单、Axios、Vite 代理。
4. **纵向请求链**：浏览器 → Vue → Axios → HTTP → Tomcat → DispatcherServlet → Controller → Jackson → JSON → Vue。
5. **数据形态变化**：表单字符串 → JavaScript 对象 → JSON → `EchoRequest` DTO → JSON。
6. **新增技术的位置**：Tomcat 接收 HTTP；Spring MVC 路由；Jackson 转换 JSON；Vite 仅在开发时代理。
7. **核心目录变化**：新增 `minimall-server` 与 `minimall-web`。
8. **API 变化**：`GET /api/hello`、`/info`、`/greet?name=`、`/users/{id}`，`POST /api/echo`。
9. **数据库变化**：无。本阶段没有 MySQL。
10. **手工验证步骤**：启动两个进程，浏览器提交表单；在 Network 查看 POST 请求和 JSON 响应。
11. **自动测试**：后端 `mvn test && mvn package`，前端 `npm ci && npm run build`。
12. **常见错误**：8080 未启动会导致代理失败；POST 缺少 JSON Content-Type 会返回 415；JSON 格式错误返回 400；错误路径返回 404。
13. **本阶段掌握判定**：能解释 `@RestController`、`@RequestBody`、`@RequestParam`、`@PathVariable`、DTO、Jackson。
14. **下一阶段为什么存在**：Echo 没有持久化，V1 加入数据库读写。
15. **checkout 当前版本**：`git checkout v0`。
