# V1 商品 CRUD

1. **本阶段目标**：让商品从页面写入 MySQL 并可读回。
2. **上一阶段有什么**：V0 只有不持久化的 Echo 请求。
3. **本阶段新增什么**：商品五个 CRUD 接口，Service、Mapper、MyBatis XML、MySQL 表与 Vue 管理页面。
4. **纵向请求链**：Vue → Axios → Controller → ServiceImpl → Mapper Proxy → XML SQL → JDBC / HikariCP → MySQL。
5. **数据形态变化**：表单 → JSON → `ProductCreateDTO` → `Product` Entity → 数据行 → `Product` JSON。
6. **新增技术的位置**：DataSource/HikariCP 管连接；MyBatis Mapper Proxy 执行 XML 中的 SQL；MySQL 持久化。
7. **核心目录变化**：增加 `dto`、`entity`、`service`、`mapper` 与 `database`。
8. **API 变化**：`POST /api/products`、`GET /api/products/{id}`、`GET /api/products`、`PUT /api/products/{id}`、`DELETE /api/products/{id}`。
9. **数据库变化**：新增 `product`；金额 `DECIMAL` ↔ `BigDecimal`。
10. **手工验证步骤**：运行 SQL、启动后端与前端；页面依次新增、按 ID 查询、编辑、列表刷新、删除；用 SQL 确认记录变化。
11. **自动测试**：`mvn test && mvn package`；`npm ci && npm run build`。
12. **常见错误**：数据库不存在、密码不正确、XML namespace 与接口不一致、未执行 schema。
13. **本阶段掌握判定**：能解释为什么没有 `MapperImpl`：MyBatis 为接口创建动态代理，根据方法名找到 XML statement 并执行 SQL。
14. **下一阶段为什么存在**：全量列表随数据增长不可用，V2 加入过滤与分页。
15. **checkout 当前版本**：`git checkout v1`。
