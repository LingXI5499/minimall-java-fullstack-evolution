# V2 分页与动态查询

1. **本阶段目标**：在大量商品中找到需要的数据，而不一次性读取全部行。
2. **上一阶段有什么**：V1 的商品 CRUD 和全量列表。
3. **本阶段新增什么**：名称模糊查询、状态与价格过滤、分页、每页 5/10/20/50 条切换。
4. **纵向请求链**：Vue 筛选表单 → Axios 查询参数 → `ProductQueryDTO` → Service 计算 offset → Mapper XML 动态 SQL → MySQL → `PageResult` → Vue 表格。
5. **数据形态变化**：查询参数 → DTO → SQL 条件与分页参数 → records/total/page/pageSize。
6. **新增技术的位置**：MyBatis `<where>` 和 `<if>` 根据非空条件拼 SQL；`LIMIT` 与 `OFFSET` 裁切结果。
7. **核心目录变化**：新增 `ProductQueryDTO`、`PageResult`，扩充 Mapper XML。
8. **API 变化**：`GET /api/products?page=1&pageSize=5&name=&status=&minPrice=&maxPrice=` 返回分页对象。
9. **数据库变化**：无新表；演示 `COUNT(*)` 和有序分页。
10. **手工验证步骤**：准备多条不同商品；逐一验证默认分页、名称、状态、价格区间、多条件组合、翻页保留条件与每页条数切换后回第一页。
11. **自动测试**：`mvn test && mvn package`；`npm ci && npm run build`。
12. **常见错误**：offset 公式 `(page - 1) * pageSize`；不带 `ORDER BY` 的分页不稳定；筛选后忘记重置 page。
13. **本阶段掌握判定**：能解释 count 查询和 records 查询为何必须使用相同过滤条件。
14. **下一阶段为什么存在**：当前接口缺少统一错误契约和严格输入校验，V3 解决工程化问题。
15. **checkout 当前版本**：`git checkout v2`。
